# Keeling Curve

Presentation for DSM-101/102 Project 4: the Mauna Loa CO₂ record (NOAA GML, monthly means since March 1958), modelled with a straight line, a polynomial trend with yearly harmonics, and an exponential trend.

Open **presentation.html**. Its last slide embeds the interactive forecaster from `index.html`.

Static files only. The numbers in `data.js` and `presentation-data.js` are exported by the Python models in the project repository.
